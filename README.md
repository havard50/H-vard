# Håvard Pedersen — artist website

Official artist website source, including the updated portrait-led design.

## Local preview

Requires Node.js 18 or newer.

```
npm ci
npm start
```

Open http://localhost:3333.

## Editing

- `index.html`: homepage and existing artist content.
- `assets/artist.css`: updated visual design layer.
- `assets/styles.css` and `assets/premium.css`: existing styles.
- `assets/content.json`: editable site content.
- `assets/main.js`: existing interactions.
- `shop.html`: store page.

Local dependencies, hosting account metadata and QA folders are excluded. Uploading this repository does not publish the website.
