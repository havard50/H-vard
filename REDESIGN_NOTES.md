# Håvard homepage revision

The homepage now uses assets/editorial.css and assets/editorial.js. The previous complete homepage remains available at archive.html, including full biography, news, gallery, press, contact form and supporting material. The shop and content editor are retained.

Concert dates come from assets/content.json. Dated events before the current Oslo date are shown only under Past performances. Undated routing is not advertised as a confirmed upcoming show.

The supplied HTML fragment was a draft with placeholder artwork, an example booking email and conflicting album years. The revised page uses existing artwork, verified streaming links, havardpedersen@me.com, and the catalogue years already documented on the official website (2021 and 2011).

Run npm ci, then npm start to preview on http://localhost:3333.
