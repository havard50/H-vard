What each block drives

The homepage and shop.html load this file at runtime. Static HTML in index.html is a fallback if the fetch fails.

  • siteMeta.feedUpdated + feedNote — “Feed last revised” line under News; note text after the date. Same date drives the visible footer “Content refreshed” line — use Stamp feed date (today) above to bump it quickly.
  • siteMeta.hostStaticTip — optional paragraph inside the footer “Hosting yourself” disclosure (e.g. one.com upload + replacing content.json).
  • feedExtras — merged into Latest updates (with timeline, live, videos); needs published, optional image / imageAlt.
  • timeline — dated cards in the News grid; sorted by published in the browser.
  • live — rows under Live & Touring; updated stamps the living feed.
  • store + storeSettings — product cards on Home and Shop; previewImage / previewAlt for art.
  • partners — Partners grid + footer: optional logoImage / logoAlt; or typographic lockup brandLine + brandSub; optional corner mark if neither logo nor brand; linkLabel for the website link text.
  • videos — Video section embeds; non-archive rows need a YouTube youtubeId.
  • recentInterviews — “Recent interviews” cards (plus archive media / audio fields when set).
  • contactForm — mailto / optional HTTPS action. Optional note (third-party form) or mailtoNote (mailto flow): only if set, a short line appears above the form for visitors — omit for a clean Contact block.

Photos gallery (stills, captions, lightbox) is edited in index.html, not in this JSON.
